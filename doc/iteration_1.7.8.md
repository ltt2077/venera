# Venera Glass 1.7.8 维护说明

这一轮以漫画源更新可靠性为主，不改阅读器架构，不新增依赖，不改变数据库和备份格式。

## 修复

- 更新源时先下载、校验同一 `key`，再通过同目录临时文件替换脚本。网络、解析或写入失败时保留原文件，并恢复 JS 运行状态。成功时只替换该源，不重新初始化所有源。
- JS 运行时由所有源共享，因此更新任务按顺序执行；连续点击同一源会合并为一次任务。一个失败任务不会阻塞后续更新。
- 更新成功或删除源时真正清除更新提示；新一轮检查替换旧提示集合，网络失败保留上次检查结果。
- 源列表支持 `fileName` / `filename`，相对路径使用实际加载地址解析，避免更换仓库后仍从旧仓库下载。只有刷新成功后才保存新地址。
- 处理非法 JSON、非法版本、重复条目、过期请求和页面退出，避免检查按钮卡住或异步操作访问已销毁页面。源 URL 中的查询参数不再进入本地脚本文件名。
- 首次初始化等待源目录创建完成，导入脚本统一使用 `.js` 扩展名。
- 空菜单不再访问不存在的首项。

## 玻璃效果的范围

在 1.7.7 已有原生底栏、标题栏、阅读工具栏和弹出页面的基础上，增加右键/长按菜单及操作浮层。iOS/iPadOS 26+ 和 macOS 26+ 各弹层仅用一个原生材质背景，按钮和文字继续沿用 Flutter。旧 Apple 系统和其他平台保持原有模糊方式。

高对比度、粗体文字或减少动态效果时关闭对应的玻璃背景。关闭玻璃后，菜单使用实色背景。没有为漫画封面网格、长列表和每个按钮增加原生视图，也没有新增持续动画或逐帧平台通信。实际 FPS、功耗、发热仍需真机对比，构建和组件测试不能替代性能测量。

## 源列表怎么用

打开 **设置 → 漫画源 → 漫画源列表**：

- **官方源列表**：继续使用上游仓库。
- **扩展源列表**：使用本仓库的 `comic_sources/index.json`，包含上游列表元数据，以及额外的 xkcd；不会自动安装任何源。

扩展列表地址：

```text
https://raw.githubusercontent.com/ltt2077/venera/glass-cloud/comic_sources/index.json
```

只添加 xkcd，也可以在添加源的 URL 输入框粘贴：

```text
https://raw.githubusercontent.com/ltt2077/venera/glass-cloud/comic_sources/xkcd.js
```

上游现有列表包含 CCC追漫台、MangaDex、カドコミ，以及自建库 Komga、Kavita 等。列入目录表示已有适配脚本，不代表所有网络、账号或地区下都能访问。

xkcd 使用站点公开 JSON 接口，支持最新作品浏览、按编号搜索、详情、单幅图片阅读；英文内容，未实现全文搜索、互动网页或账号功能。每页 4 幅，最多缓存 32 项元数据，避免一次发起大量请求。

在源页面点击 **检查更新 → 更新** 即可获取脚本新版，无需更新 App。更新依据当前源列表里的版本号；某个不在当前列表内的自定义源仍可通过该源自己的更新按钮更新。

## 源怎么制作与发布

1. 参考 [上游模板](https://github.com/venera-app/venera-configs/blob/main/_template_.js) 和 [JS API](js_api.md)，编写继承 `ComicSource` 的类。
2. 设置唯一 `key`、`version`、`minAppVersion` 和指向原始 JS 文件的 `url`。实现 `explore`、`search`、`comic.loadInfo` 和 `comic.loadEp` 中需要的接口。
3. 将 JS 放在可访问的 HTTPS 地址，并在 `index.json` 加入名称、同一 key、版本和下载 URL。修改脚本后提高版本号，再同步目录。
4. 在 App 中导入并实际验证搜索、详情、章节和图片加载，保留旧脚本以便回退。不要把账号、Cookie 或签名密钥写进公共源脚本。

本仓库的 `tool/sync_comic_sources.py` 只汇总上游元数据并链接上游 JS，不复制或修改第三方脚本。它从本地 xkcd.js 读取版本号，因此扩展源升级不需要维护两份版本号。

`source-catalog.yml` 配置每 6 小时同步一次，仅目录变化时提交。GitHub 的定时工作流必须存在于默认分支；本仓库默认分支是 `master`，实际应用分支是 `glass-cloud`，因此定时入口也需安装在 `master`（工作流始终检出 `glass-cloud`），不能只合并到应用分支就声称定时同步已生效。

## 验证边界

回归覆盖文件校验失败/写入失败的保留与清理、任务串行与重试、地址解析与格式兼容、版本比较、更新提示清理、无障碍回退和浮层点击。xkcd 的 JS 测试覆盖分页、404 跳号、编号搜索、详情、图片地址和缓存。上游 JSON 及 xkcd 官方 API 已实查；第三方源未逐个进行账号和真机全流程测试。
